# SPYDR brand and product structure

**Product name:** SPYDR by Falvorn AI  
**Repository:** `hossain0707/Falvorn-SPYDR-CEO`  
**Tagline:** One intelligence. An entire AI workforce.

## Product vocabulary

- **SPYDR Core:** AI CEO planner and strategic decision routing.
- **SPYDR Web:** network of specialist AI roles.
- **SPYDR Command Center:** owner dashboard for plans, approvals, results, cost, and audit.
- **Falvorn AI:** parent brand; this application lives in its own repository.

## Current implementation boundaries

This v1.0 application implements a Python/SQLite-based control plane, a responsive web UI, text-producing agents with configured model providers, explicit strategy approvals, and owner-triggered execution. A realistic 3D spider command-center visualization, autonomous browser/workspace tooling, and multi-user enterprise governance are **not implemented**. Do not represent these as shipped capabilities.
