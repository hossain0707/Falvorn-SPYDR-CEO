# Changelog

All notable changes to the standalone SPYDR by Falvorn AI project are recorded here.

## 1.0.0 — 2026-11-04

### Added

- Local-first owner workspace, session authentication and seven specialist agents
- CEO model-backed planning, manual plan fallback and mandatory strategy approval
- Human-triggered agent task execution and durable Markdown/text artifacts
- Recorded provider token usage and monthly preflight spending limits
- Tamper-evident SQLite audit chain and verification API
- Responsive six-view operations dashboard
- Docker/Compose, GitHub CI, Python integration tests, UI logic checks
- Documentation covering deployment, security, roadmap and upstream relationship

### Known limitations

- Not an upstream Paperclip fork or native Paperclip plugin
- No external action execution, sandboxed coding, background task queue, or multi-user RBAC
- Requires a user-configured compatible model provider for real AI execution
- Local tests do not establish real-provider compatibility or public security readiness
